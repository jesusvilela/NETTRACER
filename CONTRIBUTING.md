# Contributing to NETTRACER

Thank you for your interest in contributing to NETTRACER!

## Getting Started

1. **Node.js Requirement**: Ensure Node.js 22+ is installed.
2. **Clone & Install**:
   ```bash
   git clone https://github.com/jesusvilela/NETTRACER.git
   cd NETTRACER
   npm install
   ```
3. **Run Tests**:
   ```bash
   npm test
   ```

## Development Workflow

- Keep changes additive and non-destructive.
- Ensure all tests pass before submitting a pull request (`npm test`).
- Follow the existing ES module code style.
- Include unit tests for new functionality under `test/`.
